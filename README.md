# Data Structures and Algorithms

A structured collection of programming foundations, data structures, and algorithms. Topics are numbered to provide a suggested learning order. The folders contain practice programs and notes; add new work to the folder that best matches its topic.

## Roadmap

| Folder | Contents |
| --- | --- |
| [01-Programming-Foundations](01-Programming-Foundations/) | Programming basics, syntax, variables, input/output, operators, conditionals, and loops. |
| [02-Time-Space-Complexity](02-Time-Space-Complexity/) | Analyze algorithm runtime and memory use; learn asymptotic complexity and Big O notation. |
| [03-Arrays](03-Arrays/) | Array fundamentals, traversal, updates, and common array operations. |
| [04-Searching](04-Searching/) | Linear and binary search, including binary search on a feasible answer. |
| [05-Strings](05-Strings/) | String operations, traversal, comparison, and common string problems. |
| [06-Two-Pointers](06-Two-Pointers/) | Solve sequence and array problems by coordinating two indices. |
| [07-Sliding-Window](07-Sliding-Window/) | Process contiguous ranges efficiently with fixed-size and variable-size windows. |
| [08-Hashing](08-Hashing/) | Hash tables, maps, sets, frequency counts, and lookup-based algorithms. |
| [09-Sorting](09-Sorting/) | Sorting algorithms, their tradeoffs, and ordering data. |
| [10-Recursion](10-Recursion/) | Base cases, recursive calls, and problems that decompose into smaller instances. |
| [11-Backtracking](11-Backtracking/) | Explore choices recursively and undo them to search for valid solutions. |
| [12-Linked-List](12-Linked-List/) | Node-based sequences, traversal, insertion, deletion, and linked-list techniques. |
| [13-Stack](13-Stack/) | Last-in, first-out data structures and problems involving nested or ordered state. |
| [14-Queue](14-Queue/) | First-in, first-out data structures, dequeues, and queue-based algorithms. |
| [15-Heap-Priority-Queue](15-Heap-Priority-Queue/) | Heap operations, priority queues, and efficient minimum or maximum retrieval. |
| [16-Trees](16-Trees/) | Tree terminology, traversals, and general binary-tree algorithms. |
| [17-Binary-Search-Tree](17-Binary-Search-Tree/) | Ordered binary trees, search, insertion, deletion, and tree properties. |
| [18-Trie](18-Trie/) | Prefix trees for efficient storage and lookup of strings and shared prefixes. |
| [19-Graphs](19-Graphs/) | Graph representations, traversals, connectivity, and foundational graph algorithms. |
| [20-Advanced-Graphs](20-Advanced-Graphs/) | More advanced graph techniques and algorithms built on graph fundamentals. |
| [21-Greedy](21-Greedy/) | Algorithms that make locally optimal choices, with attention to when those choices work. |
| [22-Dynamic-Programming](22-Dynamic-Programming/) | Overlapping subproblems, state design, memoization, and tabulation. |
| [23-Bit-Manipulation](23-Bit-Manipulation/) | Binary representations, bitwise operators, and algorithms that use individual bits. |
| [24-Mathematical-Algorithms](24-Mathematical-Algorithms/) | Number theory and mathematical techniques used in programming problems. |
| [25-Advanced-Array-Techniques](25-Advanced-Array-Techniques/) | Higher-level array patterns, including prefix sums and subarray algorithms. |
| [26-Intervals](26-Intervals/) | Interval sorting, merging, overlap detection, and scheduling problems. |
| [27-Advanced-Data-Structures](27-Advanced-Data-Structures/) | Specialized data structures and techniques beyond the core structures above. |

## Languages and Practice

The repository currently includes C++ and JavaScript examples. Each topic is organized in its own folder; not every topic necessarily has exercises yet. Use the numbered order as a guide, and add source files and topic-specific notes as you work through each section.
